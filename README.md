----> Orbital simulator 
(!) About Project "Orbital Simulator".
This Project is an interactive digital 2D model of orbital mechanics of certain mega structures such as Dyson Spheres, Dyson Swarms, and also phenomenal sructures like Black Hole, stars and Two-Body System and stimulates their Orbit. 
The catalyst to this project was that people often suffer from the unstable orbits of these structures and call them Hypothetical because the building material required is too enormous and the orbit of these around the host star is very unstable 
This project solely targets to eliminate the problem by taking applied mathematics, physics to calculate the exact path the structure should travel to not get collapsed or get destructed all along while following its path. 

----> Key Elements to this Project 
.-> C# (Main language of code used in this project)
.-> Visual studio Code community version 2022 
.-> Unity (for visuals)
.-> core applied mathematics and physics (for calculation of orbit and stabilization)
